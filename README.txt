# Contact landing page

## Edit the page

Open `index.html` in any text editor. The name, role, contact details, button labels and links are written directly in that file.

Keep `landing-background.mp4` and `paolo-photo.jpg` in the same folder as `index.html`. The page uses relative file names, so it works locally and after publishing the whole folder.

To replace the photo or video, use your own files and either keep the existing names or update the matching `src` in `index.html`.

## Preview locally

Open `index.html` in a web browser. Some browsers restrict autoplay when opening files locally; the video is muted and will autoplay when hosted over HTTPS.

## Publish

Upload `index.html`, `landing-background.mp4`, and `paolo-photo.jpg` to the root of your static website hosting folder. Do not upload just the HTML file, because the photo and video are separate assets.
